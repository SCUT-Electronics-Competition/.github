# 关于本组织

**SCUT Electronics Competition** 是由华南理工大学学生与参赛者自发建设、共同维护的非官方、非营利性公益交流平台。本组织致力于整理和展示电子设计竞赛及相关科技赛事中的优秀作品、设计资料、开发经验与学习资源，为同学们提供开放、真实、可复现的项目参考，降低入门门槛，促进跨年级、跨专业的技术交流与经验传承。

我们欢迎更多同校优秀学生加入，共同补充项目资料、学习路线和实践经验。所有内容以学习交流和公益分享为目的，不用于商业经营；作品版权归原作者或原团队所有，贡献者应确保已获得必要授权。请尊重原创成果，引用时注明来源，严禁直接抄袭或将公开资料冒充原创参赛。

> 本组织为学生自发维护的非官方项目，不代表华南理工大学官方立场。
